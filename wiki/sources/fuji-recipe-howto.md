# Source: Fujifilm — "Make Your Own Film Simulation Recipe"

Official Fujifilm how-to: how to program a Film Simulation recipe into an X Series / GFX body and what each setting does. Pasted by the human; captured here per schema (not in `raw/`). Reference value only — confirms the meaning of the dials the wiki's recipe frontmatter schema encodes. The article also included an example recipe (*Nostalgic Summer* by Josh Edgoose × Fujifilm); **the human directed it not be catalogued** — it was article filler and off-taste vs the [[synthesis/photographer-profile]], so no recipe/entity pages were kept for it.

## Key claims (reference, citable)

- **Custom settings mechanics**: `IMAGE QUALITY SETTING > EDIT/SAVE CUSTOM SETTING` → pick or CREATE NEW slot → `EDIT/CHECK`; recall via the Mode dial C1–C7 or `SELECT CUSTOM SETTING`; `EDIT CUSTOM NAME` to name a slot.
- **Dynamic Range needs ISO headroom**: DR200 requires ≥1 stop over base ISO, DR400 ≥2 stops (base 160 → DR400 needs ISO ≥ 640). *This is the general rule behind the per-recipe "DR200 needs ISO ≥ ~320" caveats already on the wiki's recipe pages.*
- **Grain Effect**: roughness OFF / WEAK / STRONG, size SMALL / LARGE.
- **Color Chrome Effect**: deepens tonal range in already-saturated colours (reds/greens/yellows); OFF / WEAK / STRONG. **FX Blue**: same, blues only.
- **White Balance**: settable in K (to nearest 10K) plus R/B fine-tune.
- **Tone Curve**: higher = harsher highlights/shadows, lower = softer.
- **Color** = saturation; **Sharpness** = outline sharpen/soften; **High ISO NR** = noise reduction (also smooths outlines); **Clarity** = midtone definition with minimal highlight/shadow tone shift.
- **Exposure**: Auto-ISO (default / max / min-shutter) and exposure compensation can be baked into a custom profile on bodies without the dedicated dials.
