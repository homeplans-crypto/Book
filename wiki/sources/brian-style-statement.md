# Source: Brian — Photographic Style Statement (corrected)

Raw: `raw/brian-style-statement.md`. Supplied 2026-07-03 mid-panel with "This is what the description should have been." Authoritative where it differs from [[sources/brian-photographic-preferences]].

## Summary

Quiet, architectural, place-driven photography — the environment itself as landscape (streets, buildings, curbs, rails, lamps, pavement, weather). Goal: believable realism with emotional memory attached; the image should feel like being there, not like an imposed filter.

## Key claims

- Rejects: overcooked saturation, teal-orange grading, pastel flatness, **generic film-recipe dominance**, "social-media cinematic," dramatic subject-chasing.
- Wants: clean structure, readable depth, controlled highlights, meaningful shadows, strong texture; color restrained but alive, gently shaped rather than obviously stylized; reds/earth colors present but never loud; warmth subtle.
- Night/blue hour = "streets as landscapes": street legible as a place; artificial lights controlled, not blown; atmosphere with structure, not a generic night scene.
- Influences: quiet composition, layered light, strong shadows, human-scale architecture, atmospheric realism — composed, textured, observant, realistic, slightly poetic.

## Notable tension
