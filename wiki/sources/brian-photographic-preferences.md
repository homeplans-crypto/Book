# Source: Brian — Photographic Preferences Reference

Raw: `raw/brian-photographic-preferences.md`. Context file supplied by Brian (2026-07-02) for AI-assisted photography work.

## Summary

Brian shoots landscape, flowers, and architecture on a Fujifilm X100VI, SOOC-only via custom film simulation recipes, across all hours. The camera is an art instrument, not documentation; every recipe slot is a deliberate artistic voice, never gap-filling coverage.

## Key claims

- Aesthetic self-description: quiet, grounded, textured, found — tonalism, wabi-sabi, cinematic restraint, chiaroscuro/low-key.
  > Partially superseded by [[sources/brian-style-statement]] (2026-07-03), which recenters on believable realism and "streets as landscapes" and explicitly rejects "generic film-recipe dominance."
- Lineage: Shore, Eggleston, Sternfeld (Kodachrome documentary); Leiter, Hido, Sudek; contemporary recipe influence Mehdi Berrada.
- Current seven-slot bank (camera order): C1 Found Tonalism (Classic Chrome), C2 Close Perivolos (Classic Neg H0 S+4), C3 Mid Arch Perivolos (Classic Neg H−1 S−1, ~25–30% of shooting), C4 Honō (Classic Neg), C5 Pastel Bloom (Astia, sole NR −2 exception), C6 Loki (Classic Neg, Berrada, unchanged), C7 Raku (Acros+Ye softened). A lighting-problem-organized bank variant exists.
- Technical invariants: NR −4 universal; day/night curve principle (lifted curves need daylight, crushed curves need contained/low light); night street = Reala Ace base, Daylight WB for light-source separation, DR400; events/people = PRO Neg. Std.
- Working style: verdict-first, expert-level Fuji assumed, corpus-validated parameters over vibes (maintains a 1,058-recipe/128-creator index); prefers self-contained HTML tools.
