# Fujifilm X100VI — The 7 Best Recipes for Oklahoma (Nature, Flowers, Architecture)

Consensus result of a 15-agent panel run on 2026-07-02: 4 web scouts (Fuji X Weekly, community recipes, architecture recipes, Oklahoma light research) gathered 25 candidates; 5 discipline experts (Oklahoma landscape photographer, Fuji color scientist, botanical-macro photographer, architect, image-quality engineer) nominated and authored customs, growing the slate to 35; 5 adversarial critics (nature, flowers, architecture, Fuji-technical, Oklahoma) scored every entry; a neutral chair selected the final 7 with all critic fixes baked in.

**Mandate:** clear, crisp, clean-air images — honest-but-vivid color, no muddy haze, no retro fade — for nature/landscape, flower close-ups, and architecture (Tulsa Art Deco + OKC modern glass) in Oklahoma light.

> No raw sources ingested for this page; provenance is web URLs gathered by the scout agents, cited per recipe under *Origin*.

## Kit-wide operating doctrine

Applied across all seven recipes by five-critic consensus:

- **Grain Off everywhere** — grain costs 40MP acuity and contradicts the clean-air mandate.
- **DR200 default** (ISO floor 250); DR400 (ISO floor 500) only for blazing midday cumulus or canyon shade; the DR mode's ISO floor is a hard camera constraint.
- **EC biased to 0 / -1/3 in high sun** — published Fuji X Weekly +1/3-to-+1 guidance is calibrated for softer light than Oklahoma's.
- **Daylight-locked WB** in preference to floating Auto — wandering warmth reads as haze; series stay consistent.
- **Enable RGB histogram / R-channel blinkies** — Oklahoma reds (dirt, Gaillardia) clip the red channel before the luminance meter warns.
- **Clarity's hidden cost:** any non-zero Clarity adds ~1s write blackout per frame. Recipes that ship Clarity +2/+3 note a Clarity-0 "fast mode"; shoot RAW+JPEG and batch-add Clarity in X RAW Studio on keepers.
- **CCFX Blue never Strong on Velvia or Classic Chrome on X-Trans V** (goes navy); the sensor already renders Classic Chrome blues a step deeper than X-Trans IV.

## 1. Gaillardia (Astia flower close-up)

**Best for:** Flower close-ups — Indian blanket (Gaillardia), black-eyed Susan, roadside wildflowers; the dedicated 20-60cm working-distance recipe.

| Setting | Value |
|---|---|
| Film Simulation | Astia/Soft |
| Dynamic Range | DR200 |
| Highlight | -1 |
| Shadow | -1 |
| Color | +2 |
| Sharpness | 0 (optional +1 for black-eyed Susan dark centers — no delicate gradient there to harm) |
| High ISO NR | -4 |
| Clarity | 0 (protects petal gradients AND eliminates the ~1s write pause between wind gusts) |
| Grain Effect | Off |
| Color Chrome Effect | Strong (the load-bearing setting — rebuilds gradation inside saturated red/yellow petals) |
| Color Chrome FX Blue | Weak |
| White Balance | Daylight, +1 Red & -1 Blue (changed from Auto so series stay consistent with the rest of the Daylight-locked kit) |
| Exposure Compensation | 0 in red-dominant frames — enable RGB histogram / R-channel blinkies, the red channel clips before the luminance meter warns; +1/3 in mixed or softer light |
| ISO | 250 minimum (DR200 floor); Auto 250-1600 for breeze-fighting 1/1000+ shutter speeds |
| Field note | stop down to f/4-f/5.6 near minimum focus distance — the 23mm is soft wide open at MFD |

**Why chosen:** Highest-scored recipe in the entire slate: 9/10 from the nature critic ('strongest single recipe'), 9/10 from the flower critic ('best-reasoned for the title subject'), 9/10 from the Oklahoma critic, 8.5/10 from the Fuji-technical critic. Nominated by four of five experts including the color-science specialist, who called CCE Strong on Astia's gentle shoulder 'the only tool in the camera that addresses both halves of Indian blanket's two-tone at once.' Unanimous agreement that Clarity 0 here is correct discipline, not a brief violation — crunch destroys petal micro-gradients, and the zero write-lag is decisive in wind.

**Shooting notes:** Any daylight, best mid-morning through afternoon on frontlit/sidelit flowers. EC 0 on dense red patches (watch R-channel blinkies), +1/3 otherwise. ISO 250-1600, favoring shutter speed over base ISO in Oklahoma wind. Stop to f/4-f/5.6 at close focus. Never hand red close-ups to any Velvia recipe — switch here inside ~1.5m of a red flower.

**Origin:** Custom — botanical-macro panelist; Astia base per adaminsights.com/photoxels.com petal-detail findings + jmpeltier.com Color Chrome Effect research (pool #25). WB fix from nature critic, ISO/EC fixes from all four scoring critics.

## 2. Kodachrome 64 (X-Trans V, de-grained Oklahoma tune)

**Best for:** Red dirt roads, golden cured prairie, rusted-Americana subjects, and Tulsa Art Deco brick/terracotta in hard sun — the warm-masonry and mixed-Americana workhorse.

| Setting | Value |
|---|---|
| Film Simulation | Classic Chrome |
| Dynamic Range | DR200 |
| Highlight | 0 |
| Shadow | +0.5 |
| Color | +2 |
| Sharpness | +1 |
| High ISO NR | -4 |
| Clarity | +3 (~1s write pause; set 0 and reprocess in X RAW Studio for fast walk-around) |
| Grain Effect | Off (published Weak/Small deleted — costs 40MP acuity for film cosplay) |
| Color Chrome Effect | Strong |
| Color Chrome FX Blue | Off (correct X-Trans V call — this sensor already renders Classic Chrome blues a step deeper) |
| White Balance | Daylight, +2 Red & -3 Blue from ~10am-4pm (restore the published -5 Blue for golden hour and low sun; use +1 Red & -4 Blue on white/buff limestone facades so pale masonry doesn't drift cream) |
| Exposure Compensation | 0 to -1/3 in high sun — the published +2/3 ceiling blows glazed-tile and limestone speculars |
| ISO | 250 minimum (DR200 floor); prefer 250-800 in daylight, Auto to 6400 |

**Why chosen:** The only recipe nominated by ALL FIVE experts and included in all five critics' recommended loadouts — the strongest consensus in the panel. Scores: 8, 5 (flowers-only score), 8, 9, 9. The color-science expert called it 'the single best match between a published recipe and this environment': CCE Strong holds gradation in hematite red-orange, CCFX Blue Off is the verified V-sensor porting rule, and Shadow +0.5 + Clarity +3 engineer out Classic Chrome's retro fade. Critic-consensus fixes (Grain Off, -3B midday to stop amber cumulus, EC capped at 0) are baked in rather than footnoted.

**Shooting notes:** Best 10am-5pm hard sun and golden hour (flip WB shift to -5B after ~5pm). EC 0 to -1/3 at midday; Classic Chrome recovers shadows better than skies. ISO 250-800. Keep it OFF flowers (browns Gaillardia red toward brick) and use the +1R/-4B variant on pale facades like Boston Avenue Methodist.

**Origin:** https://fujixweekly.com/2022/11/28/kodachrome-64-fujifilm-x-t5-x-trans-v-film-simulation-recipe/ (pool #1; duplicates #10/#15 merged). Grain, WB-shift, and EC fixes applied per all five critics.

**Best for:** Everyday-carry mixed work: small-town main streets, landscapes with grass + soil + sky + people all needing to be true at once; preservation-grade honest material color on architecture; the truth reference vivid recipes get judged against.

| Setting | Value |
|---|---|
| Film Simulation | Reala Ace |
| Dynamic Range | DR200 |
| Highlight | -1 |
| Shadow | -0.5 |
| Color | +3 |
| Sharpness | +1 |
| High ISO NR | -4 |
| Clarity | +2 (set 0 for candid/fast work — kills the ~1s write pause; batch-add via X RAW Studio on keepers) |
| Grain Effect | Off |
| Color Chrome Effect | Weak |
| Color Chrome FX Blue | Weak |
| White Balance | Auto White Priority, 0 Red & 0 Blue — with two documented modes: GOLDEN HOUR (after ~6pm): switch WB to Daylight so warm light renders as warm light instead of being sterilized; RED-DIRT MODE (hematite soil/terracotta dominates): WB Daylight +1 Red & -2 Blue and Color Chrome Effect Strong (the Red Bed Reala settings) |
| Exposure Compensation | 0 to +1/3; watch R-channel blinkies in dense wildflower stands |
| ISO | 250 minimum (DR200 floor); Auto 250-3200 |

**Why chosen:** In all five critics' loadouts and nominated by four experts as the mandatory honest baseline — the only Reala Ace build (of nine in the slate) that is simultaneously crisp (Clarity +2, Grain Off) and cast-free. Scores: 8, 7, 8, 8, 8. The zero-shift WB renders Oklahoma's genuinely clear dry air neutral rather than nostalgic-warm — 'clean air rendered clean.' Two critics independently recommended absorbing #28's Daylight +1R/-2B + CCE Strong as a mode rather than a separate slot, and critic 1 folded #27's golden-hour lesson into a WB note; both merges applied, saving two slots.

**Shooting notes:** Any light. Default mode midday; flip to Daylight WB after ~6pm or prairie gold goes gray-beige; engage red-dirt mode when hematite fills the frame. Clarity 0 for reactive street/walk-around shooting (this is the kit's fast-mode toggle). Hand off to Curtain Wall Ace when curtain-wall speculars dominate.

**Origin:** Custom — pool #23, informed by FXW Reala Ace recipe (fujixweekly.com/2023/09/15/reala-ace-...) and Andre Pel / Alik Griffin analyses; absorbs #28 Red Bed Reala as its 'red-dirt mode' and #27 Tallgrass Last Light as a golden-hour WB note, per critic-1/4/5 merge recommendations.

## 4. Red Dirt Big Sky (disciplined Velvia landscape)

**Best for:** Nature/landscape drama — red-dirt canyons, prairie vistas, towering cumulus skylines, wildflower FIELDS at distance; the maximum-punch slide look that still honors 'honest-but-vivid.'

| Setting | Value |
|---|---|
| Film Simulation | Velvia |
| Dynamic Range | DR200 (switch to DR400 + ISO 500 from ~11am-3pm under blazing cumulus, or shooting into canyon shade) |
| Highlight | -1.5 |
| Shadow | -0.5 (raise to 0 if blacks read unanchored on ordinary scenes) |
| Color | +2 (deliberately NOT +4 — CCE Strong does the saturation-gradation work without red-channel clipping) |
| Sharpness | +1 |
| High ISO NR | -4 |
| Clarity | +3 (set 0 and add in X RAW Studio if shooting quickly) |
| Grain Effect | Off |
| Color Chrome Effect | Strong |
| Color Chrome FX Blue | Weak (Strong goes navy on Velvia on X-Trans V) |
| White Balance | Daylight, +1 Red & -1 Blue (locked — no floating AWB cast) |
| Exposure Compensation | -1/3 default in high sun; -2/3 reserved for white cumulus walls only (expect a +1/3 shadow lift in post at -2/3); 0 to +1/3 golden hour/overcast |
| ISO | 250 (DR200 floor; 500 if DR400); Auto to 1600 handheld |

**Why chosen:** The panel's Velvia slot, resolved in favor of the disciplined build: every expert who nominated stock Vivid Velvia attached mandatory tweaks (Daylight WB, EC 0/-1/3, Grain Off, watch Color +4) — and as the Oklahoma critic observed, 'that retuned recipe already exists as #22, which quietly outperforms the original for our dirt.' Scores: 8 (nature critic, 'the only Velvia with actual discipline'), 8.5 (Fuji-technical, 'clean bill of health' — the only Velvia with fully correct DR/ISO mechanics), 8 (Oklahoma). Color +2 + CCE Strong is the anti-clip architecture for hematite and Gaillardia fields that Color +4 cannot deliver.

**Shooting notes:** Sunny daylight; strongest with big sky and red earth in frame. EC -1/3 default. Keep beyond ~1.5m of any red flower (Velvia magenta-drifts and clips close reds — switch to Gaillardia). Keep OFF buildings (falsifies glass reflections and terracotta hue). Watch spring post-rain foliage — Velvia greens run hot; hand green-heavy frames to Prairie Ace.

**Origin:** Custom — pool #22, adapted from FXW Vivid Velvia (fujixweekly.com/2025/10/28/vivid-velvia-fujifilm-x-e5-...) with red-clip protection and Daylight WB; chosen over stock Vivid Velvia per critics 1 and 5. EC and shadow fixes applied.

## 5. Deco Chrome (Classic Chrome, de-faded, CCFX-tamed)

**Best for:** Architecture — Tulsa Art Deco facades (Boston Avenue Methodist, Philcade, Philtower), hard-shadow zigzag geometry, graphic masonry work; deliberate tripod sessions.

| Setting | Value |
|---|---|
| Film Simulation | Classic Chrome |
| Dynamic Range | DR100 at ISO 125 base (MANDATORY switch to DR200 + ISO 250 the moment glass or bright cumulus enters the frame — curtain-wall speculars clip instantly at DR100) |
| Highlight | 0 |
| Shadow | +1 |
| Color | +2 |
| Sharpness | +2 (drop to +1 if mullion or cornice edges shimmer against sky) |
| High ISO NR | -4 |
| Clarity | +3 (reduced from +4 per critic consensus — +4 stacked with Sharpness +2 sits at the 40MP halo threshold; write pause irrelevant on tripod) |
| Grain Effect | Off |
| Color Chrome Effect | Weak |
| Color Chrome FX Blue | Weak default — Strong reserved as a deliberate exception for pale masonry against sky, verified on the first frame (on X-Trans V Classic Chrome, Strong tips past 'polarized' into navy ink under a western-OK zenith) |
| White Balance | Daylight, +1 Red & 0 Blue (counters Classic Chrome's teal drift, keeps limestone/terracotta true) |
| Exposure Compensation | -1/3 |
| ISO | 125 (base — maximum per-pixel quality) |
| Note | Shoot RAW+JPEG; an Acros+R reprocess of the same frames is the free B&W alternate |

**Why chosen:** In all five critics' loadouts and nominated by three experts; the architecture expert called it 'the recipe I would have written myself.' Scores: 7, 2 (flowers-only), 8, 7.5, 8. Unique in the pool: DR100 at base ISO means zero tone-curve manipulation — true deep blacks in setback shadows instead of DR-lifted mud, the architecturally correct answer to hard Oklahoma sun. Every critic and both color-literate experts flagged the same two fixes — CCFX Blue Strong→Weak default and Clarity +4→+3 — which are baked into the block rather than left as commentary.

**Shooting notes:** Hard direct sun, mid-morning to late afternoon, when shadows are graphic. EC -1/3 fixed, ISO 125. First-frame check before using CCFX Blue Strong. Obey the DR200 escape hatch religiously near glass. Never point it at flowers or landscapes needing open shadows — it is a committed graphic tool.

**Origin:** Custom — pool #24, built on Classic Chrome trait research (jmpeltier.com; dpreview sky threads) with fade engineered out. CCFX Blue Weak default and Clarity +3 applied per the nature critic, color-science expert, architecture critic, and Fuji-technical critic.

|---|---|
| Film Simulation | Provia/STD |
| Dynamic Range | DR200 locked (switch to DR400 + ISO 500 only when cloud tops still clip at EC -1/3) |
| Highlight | -1.5 |
| Shadow | +1 (ease to +0.5 at harsh midday if lower-mids read heavy, or for architectural elevations) |
| Color | +2 |
| Sharpness | +2 |
| High ISO NR | -4 |
| Clarity | +3 (set 0 for responsive walk-around — kills the ~1s write pause; batch Clarity in X RAW Studio on keepers) |
| Grain Effect | Off |
| Color Chrome Effect | Weak |
| Color Chrome FX Blue | Strong — WITH a mandatory first-frame check against the zenith: drop to Weak if the sky reads inked or fights the subject; note CCFX is luminance-keyed and also darkens blue glass and water |
| White Balance | Daylight, 0 Red & -1 Blue |
| Exposure Compensation | -1/3 to 0 at midday to keep cumulus texture; 0 to +1/3 otherwise |
| ISO | 250 minimum (DR200 floor); 250-800 in daylight is effectively noise-free; Auto to 3200 |

**Why chosen:** In three of five critics' loadouts (1, 3, 4) and praised by the Fuji-technical critic as 'the most mechanically literate entry in the slate' (8.5/10) — it exists because it caught the pool's DR/ISO impossibility that three other custom Provias shipped. Scores: 8, 5 (flowers-only), 7, 8.5, 8. Provia's dead-neutral hue handling is the one base where CCFX Blue Strong is even defensible, and the recipe delivers the brief's most literal 'clean air': zero cast, zero grain, polarizer-like sky/cloud separation with Highlight -1.5 holding the cloud tops. Absorbs four redundant Provia customs into one slot.

**Shooting notes:** Midday through afternoon under building cumulus. EC -1/3 at noon. Run the first-frame CCFX Strong-vs-Weak check every clear-sky outing — western Oklahoma zeniths can push Strong past honest. Flip CCFX to Off and Shadow to 0 if a low-angle flower becomes the subject, or better, switch recipes. Clarity 0 is the fast-mode toggle for walking with it loaded.

**Origin:** Custom — pool #29, authored to debug #20 Prairie Clear-Air Provia's impossible DR400/ISO-125 coupling; absorbs the roles of #12/#14/#20/#35's Provia cluster. First-frame CCFX verify and midday shadow note applied per critics 1, 3, 4, 5.

|---|---|
| Film Simulation | Reala Ace |
| Dynamic Range | DR400 (non-negotiable — curtain-wall speculars are the entire problem) |
| Highlight | -2 |
| Shadow | +0.5 |
| Color | +2 (raised from published +1 per critic consensus — costs no hue honesty on Reala Ace and meets the vivid half of the brief) |
| Sharpness | +1 |
| High ISO NR | -4 |
| Clarity | +2 (tripod work; set 0 handheld to skip the ~1s write pause) |
| Grain Effect | Off |
| Color Chrome Effect | Weak (Strong over-densifies bronze and blue-green low-E tints) |
| Color Chrome FX Blue | Weak (deepens the sky reflected IN the glass without teal drift) |
| White Balance | Daylight, 0 Red & -1 Blue, locked — AWB is reliably fooled by frame-filling blue reflection and over-warms |
| Exposure Compensation | -1/3 to -2/3 in full sun; meter for the brightest glazed panel and let DR400 hold it |
| ISO | 500 in daylight (DR400 floor; effectively noiseless at 40MP); Auto to 1600, higher acceptable in twilight if needed |

**Why chosen:** The brief explicitly demands modern-glass coverage alongside Art Deco, and this is the only honest-color candidate engineered for it — the architecture critic rated it 9/10, 'the best architecture recipe in the slate,' and the Fuji-technical critic 8/10 with fully correct DR/ISO mechanics. Highlight -2 + DR400 is specular management no other honest recipe matches (Eterna Bleach Bypass matches the protection but fails color honesty by design — bronze glass must read bronze). Chosen over Zero-Lag Prairie for the seventh slot because coverage of a mandated subject beats a second Provia operational variant; Zero-Lag's Clarity-0 fast-mode trick is preserved as a toggle note on ranks 3, 4, and 6.

**Shooting notes:** Full sun on glass, any time of day; also the best twilight/blue-hour fallback in the kit (Reala Ace + held highlights handles mixed light gracefully). EC -1/3 to -2/3 keyed to the brightest panel. ISO 500 floor. Do NOT use it on landscapes — the protection stack renders skies gray and grass dull; that is Red Dirt Big Sky's or Cumulus Polarizer's job.

**Origin:** Custom — pool #32, composed from the FXW Reala Ace X-Trans V recipe (fujixweekly.com/2023/09/15/reala-ace-...) and field practice on OKC towers; the architecture critic's top-scored recipe (9/10). Color +2 fix applied per critics 3 and 4; rigid ISO cap relaxed per critic 4.

## How consensus was reached

Consensus was reached in four passes. (1) DEDUPLICATION AND VALIDITY: the 35-entry slate was first collapsed to ~24 distinct recipes per the critics' unanimous finding — Kodachrome 64 x3 (#1/#10/#15), Vivid Velvia x3 (#2/#8/#16), The Rockwell x2 (#4/#13), #11=#17 (identical settings, two names), and the #7/#14 'Prairie Clear' name collision. Entries with settings invalid on the X100VI were struck or required repair: #3 (5150K does not exist in Fuji's WB menu), #7/#13/#14/#20 (ISO recommendations below their DR mode's floor — DR200 forces ISO 250, DR400 forces ISO 500). Anti-brief entries (negative Clarity as shipped: #6/#11/#17/#18; Sharpness +4 halo-crunch: #4/#13) were excluded unless a critic-endorsed fixed variant existed. (2) SCORING CONVERGENCE: each surviving recipe was tallied by expert nominations (weighting the discipline-relevant expert highest) and by its appearance in the five critics' explicit 7-slot loadout recommendations. Kodachrome 64, Prairie Ace, Deco Chrome, and Gaillardia appeared in effectively all five critic loadouts; Cumulus Polarizer in three; a Velvia landscape slot in all five (with disagreement on which build); Curtain Wall Ace in one but rated 9/10 by the discipline critic. (3) COVERAGE CONSTRAINT: the brief mandates nature/landscape + flowers + Art Deco + modern glass, all crisp/clean-air. This forced two tie-breaks: Curtain Wall Ace took the seventh slot over Zero-Lag Prairie (3 critic loadouts) because Zero-Lag duplicates Cumulus Polarizer's Provia territory while modern glass would otherwise go uncovered by any honest-color recipe; and slot-saving merges endorsed by critics were executed — #28 Red Bed Reala became Prairie Ace's documented 'red-dirt mode,' #27 Tallgrass Last Light became its golden-hour WB note, and Zero-Lag's Clarity-0 fast-mode toggle was written into three recipes' notes. (4) FIX APPLICATION: every consensus critic fix was baked into the final settings blocks rather than left as footnotes — Grain Off kit-wide (40MP acuity, five-critic consensus), EC re-biased to 0/-1/3 for Oklahoma high sun kit-wide (published FXW +1/3-to-+1 guidance is calibrated for softer light), Daylight-locked WB replacing floating AWB (wandering warmth reads as haze), CCFX Blue never Strong on Velvia/Classic Chrome on X-Trans V (Weak default on Deco Chrome; Strong retained only on the neutral Provia base with a mandatory first-frame verify), Deco Chrome Clarity +4→+3 (halo threshold), Curtain Wall Ace Color +1→+2, Gaillardia WB Auto→Daylight and ISO ceiling 800→1600. The kit balances film-sim diversity deliberately: one Astia, one Velvia, one Provia, two Classic Chrome (opposite tunings), two Reala Ace (opposite roles), with a shared operating doctrine: DR200 default with DR400/DR100 as deliberate exceptions, RGB histogram/R-channel blinkies enabled, RAW+JPEG for X RAW Studio Clarity passes on keepers.

## Dissents and bench recipes

1) THE VELVIA SLOT: Critics 3 and 4 recommended keeping the canonical FXW Vivid Velvia (#2, with Daylight WB/EC/grain fixes); critic 1 preferred Vivid Chrome (#9, with Sharpness -2→+1); critic 5 argued the fixed #2 'already exists as #22 and #22 outperforms it for our dirt.' The chair sided with #22 Red Dirt Big Sky because it was the only Velvia the Fuji-technical critic passed with a 'clean bill of health' and its Color +2 + CCE Strong anti-clip architecture is what the experts' tweak lists were converging toward anyway. Owners preferring Ritchie's canonical look can load #2 with the documented fixes at no coherence cost. 2) ZERO-LAG PRAIRIE (#35): appeared in three critic loadouts (2, 4, 5) as the everyday-carry answer to the ~1s Clarity write pause — it lost the seventh slot to Curtain Wall Ace only because the brief mandates modern-glass coverage; it is the panel's first-choice bench swap-in, and its core insight survives as the Clarity-0 fast-mode toggle documented on ranks 3, 4, and 6. 3) MONOCHROME: critics 1 and 5 wanted Acros+R Deco Monochrome (#21, Shadow +2→+1.5) in the kit, and critic 3 wanted Setback & Spandrel (#33) for glass-safe B&W; the chair excluded both since the brief is color-first and Deco Chrome's prescribed RAW+JPEG + Acros+R reprocess covers the B&W Deco frame for free — but shooters wanting SOOC monochrome should bench #21 (masonry) and #33 (glazing) as a pair. 4) SITUATIONAL SPECIALISTS: Backlit Petal (#30, scored 8-9 by three critics) and Prairie White (#31, 7-8) fill genuine gaps (transmitted-light petals; white/pastel subjects) and were strongly defended by the flower critic — they lost to generality and belong on the bench for planned dawn/dusk flower sessions, along with Gloss Mountain Gypsum (#26) for two-tone white-on-red terrain and Crystal 125 (#34) for even-light tripod max-acuity work. 5) UNRESOLVED SLATE-LEVEL COMPLAINTS: all five critics noted remaining gaps no pool candidate fills — storm-front/overcast dramatic light, blue-hour city work, and purple/blue wildflowers (spiderwort, prairie verbena) — the panel records these as future scouting targets rather than forcing weak picks. 6) CCFX BLUE STRONG ON PROVIA (rank 6): critics 1, 4, and 5 all flagged this as asserted-not-verified; it ships only with the mandatory first-frame zenith check, and a minority position (nature critic) would ship it at Weak outright.
